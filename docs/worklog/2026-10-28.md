## What was done
1. **Read the tools:** `add_joint` and `set_scale` write decision 0012's two spec parts;
   `spec_state` read only that kind; `preview_twin` previewed only it; `inspect_geometry` fits
   circles across x only. The pipeline, the CLI and the views already took a `PartsSpec`.
2. **The draft** (`workspace.runs`): a several-part spec's pieces in `geometry_spec.parts.json`,
   each checked by its own model when set; `geometry_spec.json` written only while the pieces make
   a valid `PartsSpec`, and removed when a change breaks it. One kind per run.
3. **Seven tools** set the pieces (`set_spec_frame`, `set_cut_list`, `set_spec_part`,
   `set_spec_joint`, `remove_spec_entry`, `set_scale_length`, `set_size_checks`); **`fit_circles`**
   measures along x, y or z; **`preview_twin`** previews either kind, and for several parts lists
   the **holes** (`parts_spec.open_loops`): each cut part's open loops across a removed part, at
   the centres a patch accepts. The job status names the kind's step. `add_joint`, `set_scale` and
   the HA5C's runs are unchanged.
4. **Tests:** the workspace draft (valid only while whole, refusals, kinds apart); a quick MCP test
   setting the Phase 1 drill press's spec through the tools (2 s); a slow one that previews it,
   patches the holes the preview reports (the synthetic cut list's table box opens the boxes under
   it), previews again with none, and submits (about 90 s); `open_loops` on an open box.
5. **Docs:** decision 0028 (proposed); the procedure's section 5b; decision 0013's amendment; the
   README; the plan.
6. **v4's holes, as the new preview reports them:** four loops across a removed part. Two are
   covered by stand-ins (the generated handles' root inside the hub's boss; the guard's bottom,
   where the stand-in chuck passes). Two are one seam seen from both sides, where the quill's
   collar meets the head's underside, now touching the removed rod's foot. That seam was there in
   v1-v3; it shows from below when the quill is lowered. Left for Daniel's review (an open
   question in the PR).
7. **The PR's PNGs** (`docs/images/2026-10-28-t33901-v4/`): v4's spec re-rendered in a scratch
   copy of the data folder with the new palette (v4's own views repeat three colours): the parts,
