    `pipeline_result.py`. On a scratch copy, `ruff --fix` clears them and the JSON Schema is unchanged.
    We kept E, F, I for now (open question for the team).
  - Oxlint exits 0 on warnings (`debugger` probe reported as a warning).
- Hiccups, all resolved:
  - The version-lookup script crashed with `UnicodeEncodeError` (cp1252 console); `python -I` ignores
    `PYTHONIOENCODING`, so it was rerun with `-X utf8`.
  - The first `git add` failed (`pathspec 'KICKOFF_PROMPT.md' did not match`); nothing was staged; rerun
    without that file.
  - The first TypeScript probe hit TS5112 (tsc refuses file arguments next to a `tsconfig.json`); rerun
    with `--ignoreConfig`.
  - npm offered an upgrade to 12.2.0; not done (it would be an unapproved install).
