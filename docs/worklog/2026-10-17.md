## Problems and fixes
- **Generator install.** Without a numba floor the resolver picked `llvmlite==0.36.0`, which does
  not build on Python 3.12. Fixed with `"numba>=0.61"`.
- **First real generation failed** with `FileNotFoundError` for a relative `job.json` path: the child
  process runs in the output folder. `run_job` now resolves paths, and `test_relative_paths_work`
  covers it (checked to fail without the fix).
- **`radial_profile` read 0 on a coarse cylinder** because it used vertices; it now uses surface
  samples.
- **Test modules** could not import each other (`tests/` is not a package); the synthetic indexer
  moved to a conftest fixture.
- **`_part_mesh`** wrapped its own `ExportError` a second time; fixed.
- **NVIDIA's ASCII performance rule** failed v1; binary `.usdc` fixed it in v2 (decision 0012).
- **Temporary files.** hy3dgen left seven `.ply` files (about 77 MB) in `%TEMP%` on every run. Fixed;
  a test checks it with a fake job (shown to fail without the fix), and the GPU test checks it with
  the real generator.
- **Part GLBs** carried the generator's temporary mesh name, so equal geometry gave different files.
  Fixed; a test shows it fails without the fix. v2's part files predate this fix; their geometry is
  unaffected.
- **Lint and syntax.** Ruff findings (E501, BLE001, RUF007, ISC004, SIM102) were fixed. A broken
  string from a shell heredoc in `conftest.py` was also fixed.
- **Reading PDFs.** The Read tool cannot render PDFs here (it needs pdftoppm), so pypdf extracted
  the text. The drawing was therefore never seen as an image: its views were inferred from text
  positions and marked `[INFERENCE]`.
- **Photo format.** The Haas photo is a CMYK JPEG. rembg handled it; a crop for the spindle
  comparison needed `convert("RGB")`.
